# 카카오톡 단톡방 월간 출석 및 벌금 집계기

카카오톡 대화 내보내기(`.txt`) 파일을 기준으로 월간 출석 현황, 100% 올출자, 주간(`일~토`) 미출석 벌금을 집계하고 텍스트/CSV 리포트를 생성합니다.

## 출석 및 벌금 규칙

- **출석 주기:** 매일 `06:00` ~ 익일 `06:00`
- **출석 인정 조건:**
  1. `holidays.json`에 등록된 공휴일(해당 일자 전원 출석)
  2. `offline_attendance.json`의 해당 날짜 명단에 이름이 포함된 경우
  3. 해당 주기 내에 `MMDD`와 `이름`이 포함된 메시지 작성(예: `1124 홍길동`, `1125 성춘향`)
- **주간 및 이월 기준:** 일요일 ~ 토요일 단위이며, 토요일이 속한 월로 귀속(달이 넘어가는 주는 다음 달로 이월)
- **벌금 기준:** 주간 미출석 `3일` 이상 시 미출석일당 `1,000원` 부과, 월간 단위로 총 벌금 합산

## 폴더 구성

```text
출석체크폴더/
├── 출석체크.exe               # 실행 파일 (zip 배포 시 포함)
├── members.json              # 출석 대상 이름 목록
├── holidays.json             # 공휴일 목록 (YYYY-MM-DD)
├── offline_attendance.json   # 날짜별 오프라인 참석자 명단
├── exports/                  # 카카오톡 대화 내보내기 .txt 파일 위치
└── reports/                  # 집계 결과 (.txt, .csv) 자동 저장 폴더
```

## 사용 방법

1. 카카오톡 채팅방에서 **대화 내용 내보내기**로 `.txt` 파일을 저장한 뒤 `exports/` 폴더에 넣습니다. (여러 개면 가장 최근 파일명을 기준으로 읽습니다.)
2. `members.json`, `holidays.json`, `offline_attendance.json`을 현재 모임 일정과 인원에 맞게 수정합니다.
3. `출석체크.exe`를 더블클릭해 실행합니다.
4. 조회할 월(`YYYY-MM`)을 입력하거나 `Enter`를 눌러 기본값으로 집계합니다.
5. 화면 출력과 함께 `reports/출석현황_YYYY-MM.txt`, `reports/출석현황_YYYY-MM.csv` 파일이 생성됩니다.

> **참고:** 개인 빌드 `.exe` 실행 시 Windows SmartScreen 경고가 뜨면 **추가 정보 → 실행**을 선택하세요.
